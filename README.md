# Web Scraping Using Python and BeautifulSoup

## Task 1: Web Scraping

This project demonstrates web scraping using Python,
Requests and BeautifulSoup.

## Objective

The objective of this project is to extract useful data
from a public website and create a custom dataset.

## Technologies Used

- Python
- Requests
- BeautifulSoup
- CSV
- Visual Studio Code

## Website

https://books.toscrape.com/

## Data Collected

The project extracts:

- Book Title
- Price
- Availability
- Rating
- Book URL
